tonies-api

Asynchronous Python SDK for the Tonies cloud API and Toniebox real-time events.

Overview

⚡
Fully async
Built on httpx and websockets. Works naturally with asyncio.
🔐
Auto token refresh
OAuth2 via Keycloak. Expired access tokens are renewed transparently — no manual intervention needed.
📡
Real-time events
WebSocket/MQTT client with automatic reconnection, exponential backoff, and topic re-subscription.
🧱
Type-safe models
All API responses are validated by Pydantic v2. camelCase API aliases are handled automatically.

Installation

Requires Python ≥ 3.14.

# from source
git clone https://github.com/Raphzer/tonies-api.git
cd tonies-api
pip install .

# editable / development
pip install -e .

Dependencies installed automatically: httpx, websockets, pydantic, beautifulsoup4, python-dotenv.

Quick start

Create a .env file at the root of your project:

TONIE_USERNAME=your_email@example.com
TONIE_PASSWORD=your_password

Fetch data and configure a Toniebox

import asyncio, os
from dotenv import load_dotenv
from tonies_api import TonieAPIClient

async def main():
    load_dotenv()
    async with TonieAPIClient(os.getenv("TONIE_USERNAME"), os.getenv("TONIE_PASSWORD")) as client:

        user = await client.tonies.get_user_details()
        print(f"Logged in as {user.first_name} {user.last_name}")

        boxes = await client.tonies.get_households_boxes()
        for box in boxes:
            print(f"  {box.name} — TNG: {box.is_tng}, MAC: {box.mac_address}")

        if boxes:
            box = boxes[0]
            await client.tonies.set_max_volume(box.household_id, box.id, 75)
            await client.tonies.set_toniebox_name(box.household_id, box.id, "Living room")

asyncio.run(main())

Real-time events (WebSocket)

import asyncio, os
from dotenv import load_dotenv
from tonies_api import TonieAPIClient

async def on_event(topic: str, payload: dict):
    print(f"[{topic}] {payload}")
    if "online-state" in topic:
        print(f"  → Box is {'online' if payload.get('onlineState') else 'offline'}")
    elif "metrics/battery" in topic:
        print(f"  → Battery: {payload.get('percent')}%")

async def main():
    load_dotenv()
    async with TonieAPIClient(os.getenv("TONIE_USERNAME"), os.getenv("TONIE_PASSWORD")) as client:
        client.ws.register_callback(on_event)
        await client.ws.connect()

        boxes = await client.tonies.get_households_boxes()
        for box in boxes:
            subscribed = await client.ws.subscribe_to_toniebox(box)
            if subscribed:
                print(f"Subscribed to {box.name}")

        await asyncio.sleep(300)

asyncio.run(main())

TonieAPIClient

Main entry point. Always use as an async context manager — authentication, session management, and cleanup are handled automatically.

Attribute Type Description
client.tonies TonieResources Data fetching and device configuration
client.ws TonieWebSocket Real-time WebSocket/MQTT client
client.auth TonieAuth OAuth2 authentication handler

Authentication

Authentication uses a full OAuth2 authorization code flow via Keycloak. The access token is renewed automatically when it expires — no action is needed from the caller.

The renewal strategy is: attempt a refresh_token grant first; fall back to a full re-login if the refresh token is expired or rejected by the server.

Note: Tokens are tracked with time.monotonic() and renewed 30 seconds before expiry to avoid race conditions on slow networks.

Data methods — client.tonies

async get_user_details() → User

Returns the authenticated user's profile and feature flags (region, content ownership, etc.).

async get_households() → List[Household]

Returns all households associated with the account.

async get_households_boxes() → List[Toniebox]

Returns all Tonieboxes across all households. Each Toniebox includes the is_tng property indicating next-gen capability.

async get_tonies() → List[HouseholdWithTonies]

Returns a full overview of all content Tonies, creative Tonies, and discs per household.

async get_children(household_id: str) → List[Child]

Returns children profiles for the given household, including their associated Tonieboxes.

async get_household_members(household_id: str) → HouseholdMembersResponse

Returns current memberships and pending invitations for the given household.

async get_content_tonie_details(household_id: str, tonie_id: str) → List[ContentTonieDetails]

Returns detailed information for a specific content Tonie, including owned tunes and chapter data.

Configuration methods — client.tonies

All methods require household_id: str and toniebox_id: str as first arguments and return an updated Toniebox object.

Performance: Toniebox metadata is cached for 30 seconds. Calling several set_* methods in sequence issues only one GraphQL request instead of one per call.
Method Parameter Constraints
set_max_volume(…, volume) all int TNG: 25–100 · Classic: 25, 50, 75 or 100
set_max_headphone_volume(…, volume) all int TNG: 25–100 · Classic: 25, 50, 75 or 100
set_led_brightness(…, level) all str 'on', 'off' or 'dimmed'
set_toniebox_name(…, name) all str Non-empty string
set_accelerometer(…, enabled) all bool
set_tap_direction(…, direction) all str 'left' or 'right'
set_lightring_brightness(…, brightness) TNG only int 0–100
set_bedtime_max_volume(…, volume) TNG only int 0–100
set_bedtime_headphone_max_volume(…, volume) TNG only int 25–100
set_bedtime_lightring_brightness(…, brightness) TNG only int 0–100

TNG-only methods raise ValueError if called on a non-TNG box. Use box.is_tng to check compatibility before calling.

WebSocket methods — client.ws

async connect()

Opens the WebSocket connection, performs the MQTT handshake (CONNECT / CONNACK), and starts the reconnection supervisor in the background. Raises TonieConnectionError if the initial connection fails.

async disconnect()

Cancels the reconnection supervisor, closes the WebSocket gracefully, and cancels all background tasks.

async subscribe_to_toniebox(box: Toniebox) → bool

Subscribes to the wildcard topic external/toniebox/{mac_address}/# for the given box.

Returns True if the subscription was sent. Returns False (with a warning log) if the box does not support WebSocket events — the loop is not interrupted, allowing mixed fleets to work correctly.

async subscribe(topics: list[str])

Sends an MQTT SUBSCRIBE packet for the given topics. Topics are persisted and automatically re-sent after each reconnection. If called before connect(), topics are queued and sent when the connection is established.

async register_callback(fn) → Callable

Registers an event handler. fn must be async def fn(topic: str, payload: dict). Returns an unregister function — call it to remove the callback.

async def handler(topic: str, payload: dict):
    print(topic, payload)

unregister = client.ws.register_callback(handler)
# later:
unregister()
async send_toniebox_command(mac_address, command_type, payload)

Sends a raw MQTT PUBLISH (QoS 1) to external/toniebox/{mac}/app-control/{command_type}.

mac_address: str
MAC address of the target box (colons optional)
command_type: str
Command endpoint, e.g. 'sleep', 'stl', 'sync'
payload: dict
Optional JSON body — defaults to {}
async sleep_now(mac_address: str)

Convenience method — activates sleep timer (stl) for 300 s, then sends the sleep command.

MQTT topics

All events received by your callback have the shape (topic: str, payload: dict). Topics follow the pattern external/toniebox/{mac_address}/....

Topic suffix Description Key payload fields
…/online-state Box connected or disconnected onlineState: bool
…/metrics/battery Battery level update percent: int
…/metrics/headphones Headphone plug/unplug connected: bool
…/playback/state Tonie placed on or removed from the box tonie: str
…/app-reply/bedtime-state Current bedtime mode status
…/changed-properties General property change notification
…/settings-applied Settings successfully applied on the box
…/setup/status Setup progress update

Automatic reconnection

The WebSocket client is supervised by a background task that monitors the connection and reconnects automatically when it drops.

Parameter Default Description
_RECONNECT_BASE_DELAY 2 s Delay before the first retry
_RECONNECT_MAX_DELAY 120 s Maximum delay (exponential backoff ceiling)
_RECONNECT_MAX_RETRIES 0 0 = retry forever

On each reconnection attempt, the access token is refreshed before opening the new connection. All previously subscribed topics are re-sent immediately after a successful CONNACK. A voluntary disconnect() cancels the supervisor immediately without triggering a reconnection.

Models

All models are Pydantic v2 BaseModel subclasses. They accept camelCase field names from API responses via aliases, and expose snake_case attributes in Python.

Toniebox

Field Type Description
id str Unique device identifier
name str Display name
mac_address str MAC address (used for MQTT topics)

is_tng bool Property — True if Toniebox Go / next-gen

max_volume int Current speaker volume limit
max_headphone_volume int Current headphone volume limit
led_level str 'on', 'off' or 'dimmed'
tap_direction str 'left' or 'right'
accelerometer_enabled bool
bedtime_schedules List[BedtimeSchedules] Configured bedtime schedules

Exceptions

Exception Inherits from Raised when
ToniesApiError Exception Base — catch this to handle any library error
